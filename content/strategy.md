## Robot Strategy

A high-scoring Robot Game performance requires clear prioritization, time management, and contingency preparation during the 2.5-minute match window.

### Strategic Priorities

- **Mission Prioritization:** We group missions geographically across the mat, combining multiple objectives into single launch runs to minimize return travel and transition time in home base.
- **2.5-Minute Match Management:** Each team member has a specific designated role (technician, attachment handler, program selector) to ensure swift attachment swaps within seconds.
- **Risk Management & Baseline Points:** We establish safe, high-reliability baseline runs first, followed by higher-risk bonus missions when clock time permits.
- **Contingency Procedures:** If a mission aborts or an unexpected field element shifts, the team follows pre-planned fallback routines rather than improvising.

### Match Routine Overview
1. **Launch 1 (0:00 - 0:45):** Baseline mission run targeting high-certainty field objectives.
2. **Launch 2 (0:45 - 1:30):** Far-field multi-mission run using passive guidance walls.
3. **Launch 3 (1:30 - 2:15):** High-point precision challenge run.
4. **Final Return (2:15 - 2:30):** Return to home base for final parked points.
