# Team Content Folder

Welcome to the Raybotics 2026 content folder!

### How to update website content:
1. Open any `.md` file in this folder:
   - `about.md`: Information about the team, mission, and focus areas.
   - `values.md`: Team Core Values and principles.
   - `design.md`: Robot design philosophy, mechanisms, and key components.
   - `strategy.md`: Match strategy, time management, and contingency plans.
   - `resources.md`: Links, rule updates, and helpful tools.
2. Edit the text using simple Markdown formatting.
3. Commit or save your changes.

The website will automatically load and format your updates! No HTML editing needed.
